# Contributing

Contributions are welcome through GitHub pull requests. Please keep each pull request focused, explain the behavior it changes, and include or update tests when practical.

These extension repositories are published from the Mango monorepo. Maintainers may integrate an accepted change into Mango before synchronizing it back here, so commit hashes may not be preserved across repositories.

By submitting a contribution, you agree that your contribution is licensed under the MIT License included in this repository.
